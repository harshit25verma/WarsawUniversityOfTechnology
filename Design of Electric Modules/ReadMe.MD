## `/ build breakdown`

```
CIRCUIT DESIGN
  └── Schematic drawn in Eagle CAD
        │
        ▼
PCB LAYOUT
  └── Board designed in Eagle
        │
        ▼
PCB MANUFACTURING  ──  Done by hand
  ├── Board printed
  ├── Board drilled
  └── Components soldered
        ├── Touch sensor
        ├── Transistors
        └── LEDs
        │
        ▼
CASING DESIGN
  └── Arcade Machine modelled in CAD
        │
        ▼
3D PRINTING
  └── Casing printed & cleaned
        │
        ▼
ASSEMBLY
  └── PCB installed inside casing → ✅ Fully functional
```
